## Process, configuration and middleware

Reset is explicitly destructive and only exercised against owned disposable data. Existing brig-schema/brig-index operator utilities remain supported separately; Go never delegates serving behavior to native Brig.

Native body parser failures return 400 JSON with `code`, `message`, `label=bad-request` and JSON UTF-8 content type. Preserve original asserted messages and structured errors; no broad normalization of errors, identifiers, auth material, status, headers or ordering. Dynamic timestamps/random identities may be compared relationally only in specifically declared focused probes; original assertions remain unchanged.

Startup constructs the environment, checks Cassandra schema94, runs existing PostgreSQL migrations, starts internal events, optional SES feedback, TURN/SFT discovery, auth metrics and pending-activation cleanup. Preserve ACK/retry/payload/routing, journal/search/remote/Spar effects and deletion ordering. Expired pending rows are removed, pending invited accounts deleted and cleanup repeats with native error/delay behavior (Brig.Run.pendingActivationCleanup). Shutdown closes listener and drains accepted requests for native default30 seconds, then cancels tasks and closes dependencies (WAI.Utilities.Server:134–150). No Haskell background repairs or stronger global atomicity claims.

## Inherited concerns and qualification limits

The inventory records unsupervised background threads, documented additional-index deleted-user retention, explicit configured TLS verification bypass, best-effort/local claim locks and password-reset TTL rewrite/race concerns. Additional serious source concern: `Wire.API.MLS.Validation.validateCredential:109` explicitly leaves X509 credential signature checking for future work. It extracts identity/key and checks key scheme/equality/identity plus leaf/package signatures, but that function does not validate certificate signature/chain. This is a source finding, not a reproduced exploit or permission to change acceptance policy. Preserve native behavior and record improvement separately.
